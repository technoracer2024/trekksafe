⌚ Wearable Band
ESP32 microcontroller with MAX30102 (HR + SpO2) and MPU6050 (accelerometer + gyroscope). Reads vitals every second, processes alert logic locally.
🧠 Smart Alert Logic
Multi-sensor fusion — HR threshold + SpO2 drop + low movement = genuine emergency. Eliminates false positives from normal climbing exertion.
📡 LoRa Network
RYLR998 module at 915MHz. 5–7km range through mountain terrain. No cellular signal required. Gateways every 2km relay data via 4G to dashboard.
🏥 Command Dashboard
Real-time map of all active trekkers, live vitals, one-click dispatch. Transforms medical posts from reactive to proactive command centres.
💰 ₹650 Rental Model
₹600 refunded on device return. ₹50 service fee. Mirrors Vaishno Devi RFID card system. Accessible regardless of income level.
System Overview
Four Steps from Detection to Rescue
01 / MONITOR
⌚
Continuous Sensing
ESP32 reads HR & SpO2 via MAX30102 and movement via MPU6050 every second — even offline.
02 / ANALYZE
🧠
Sensor Fusion
Cross-references all sensors. High HR + falling SpO2 + low movement = real emergency, not just climbing.
03 / ALERT
🔔
15-Second Window
Buzzer fires. Pilgrim has 15 seconds to confirm safety. No response = automatic LoRa alert to help centre.
04 / RESPOND
🚁
Coordinated Dispatch
Dashboard highlights nearest centre. Team dispatched with live vitals and location. No phone call needed.
