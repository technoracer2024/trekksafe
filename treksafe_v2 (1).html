TrekSafe is a wearable emergency response system for elderly pilgrims on high-altitude treks. It monitors health in real time, detects genuine emergencies using smart sensor fusion, and alerts rescue teams automatically — before collapse occurs.

⌚ Wearable Band
ESP32 microcontroller with MAX30102 (heart rate + SpO2) and MPU6050 (accelerometer + gyroscope). Continuously reads vitals every second.
🧠 Smart Alert Logic
Multi-sensor fusion — HR threshold + SpO2 drop + low movement = genuine emergency. Eliminates false positives from normal climbing exertion.
📡 LoRa Network
RYLR998 module at 915MHz. 5–7km range through mountain terrain. No cellular signal required. Gateways every 2km connect to dashboard via 4G.
🏥 Help Centre Dashboard
Real-time map of all active trekkers, live vitals, one-click dispatch. Transforms medical posts from reactive to proactive command centres.
💰 ₹650 Rental Model
₹600 refunded on return. ₹50 non-refundable service fee. Mirrors Vaishno Devi RFID card system. Accessible to every pilgrim regardless of income.
System Overview
Four Steps from Detection to Rescue
01 / MONITOR
⌚
Continuous Sensing
ESP32 reads HR & SpO2 via MAX30102 and movement via MPU6050 — every second, without interruption, even offline.
02 / ANALYZE
🧠
Sensor Fusion Logic
Cross-references all three sensors. High HR + falling SpO2 + low movement = genuine emergency, not just climbing exertion.
03 / ALERT
🔔
15-Second Window
Buzzer fires. Pilgrim has 15 seconds to confirm safety. No response = automatic transmission of vitals + location via LoRa.
04 / RESPOND
🚁
Coordinated Dispatch
Dashboard highlights nearest help centre. Team dispatched with live vitals and location. No phone call — just immediate response.
